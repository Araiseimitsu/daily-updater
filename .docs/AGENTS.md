# 開発者情報 (AGENTS.md)

## プロジェクト名
Daily CLI Updater（毎朝のCLIアプリ一括アップデーター）

## 開発者・組織
- **開発者**: ユーザー様 ＆ Antigravity AI Assistant
- **組織**: ローカル個人開発環境
- **連絡先**: ローカルプロジェクト管理（本リポジトリ内 `.docs/update.md` に履歴を記録）

## 運用メモ
- 本プロジェクトは Windows ローカル環境向けに設計された、Python + ローカルWeb UI によるCLIアプリ更新管理ツールです。
- 起動コマンドは `py -3.14 main.py`（または `start_updater.bat`）を使用します。
