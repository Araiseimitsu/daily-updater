# Daily CLI Updater

毎朝実行する複数の CLI ツール（`claude`, `codex`, `agy`, `agent`, `@opencode/cli`, `grok` など）を、ブラウザ上のシンプルな UI から**ワンクリックで一括（並列）または個別アップデート**できるローカル Web アプリです。

## 主な機能
- **一括並列アップデート**: 登録済みの有効アプリを並列実行（並列数は 1〜8 で即座に変更可能）して待ち時間を大幅短縮。
- **個別 / 選択 / 失敗のみ再実行**: 1アプリだけの更新、チェックボックスで選んだ複数アプリの更新、エラーになったアプリだけの再実行に対応。
- **簡単な登録・編集・解除**:
  - 「＋ アプリ登録」からテンプレート補助付きで即座に追加可能。
  - 各カードのスイッチで、削除せずに一括対象からワンクリック除外／復帰が可能。
  - 並び替え（↑↓）・カテゴリ絞り込み・検索・JSON エクスポート／インポート対応。
- **リアルタイムログ表示**: Server-Sent Events (SSE) により、各ツールの実行ログと進捗バーをライブ表示。
- **PowerShell プロファイル関数対応**: `agent` のように PowerShell プロファイルで定義されている関数や `.ps1` / `.exe` / `npm` コマンドをそのまま実行可能。

## 起動方法
### 方法1: ワンクリック起動
`start_updater.bat` をダブルクリックするとローカルサーバーが起動し、自動でブラウザ (`http://127.0.0.1:8765`) が開きます。

### 方法2: コマンドラインから起動
```powershell
py -3.14 main.py
```

### デスクトップショートカットを作成したい場合
```powershell
pwsh -ExecutionPolicy Bypass -File .\create_shortcut.ps1
```

## オプション引数
- `--port 8765`: ポート番号を変更
- `--no-browser`: ブラウザを自動で開かずに起動
- `--debug`: デバッグログを有効化（ログは `logs/updater.log` に保存）
